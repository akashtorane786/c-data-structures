# C Data Structures & Algorithms

A collection of C implementations demonstrating fundamental data structures and commonly used algorithms. This repository focuses on practical implementations, problem-solving, and understanding how data structures work internally.

## Implementations

1. Stack Using Array
2. Postfix Expression Evaluation
3. Infix to Postfix Conversion
4. Circular Queue
5. Double Ended Queue (Deque)
6. Stack Using Two Queues – Costly Pop
7. Stack Using Two Queues – Costly Push
8. Queue Using Two Stacks
9. Singly Linked List
10. Doubly Linked List
11. Circular Linked List
12. Binary Search Tree
13. Sorting Algorithms
    - Insertion Sort
    - Merge Sort
    - Quick Sort
    - Heap Sort

## Technologies

- C Programming
- GCC Compiler
- Visual Studio Code
- MSYS2 UCRT64

## Compilation and Execution

Compile a program:

```bash
gcc filename.c -o program
```

Run on Windows PowerShell:

```powershell
.\program.exe
```
